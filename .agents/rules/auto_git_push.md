# Project Rules for Webkel Semampir

## Automatic Git Push on Changes
- Setiap kali selesai melakukan perbaikan atau perubahan kode yang sudah diverifikasi dan disetujui, **WAJIB** langsung melakukan git commit dan `git push origin main`.
- Hal ini agar Vercel otomatis melakukan deployment dan sinkron dengan repositori secara konsisten.
- Jaga konsistensi kode dan jangan mengubah layout yang sudah disetujui user tanpa instruksi eksplisit.
